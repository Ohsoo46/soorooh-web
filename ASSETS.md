# SOOROOH asset provenance

All photographic assets were generated with the built-in Imagegen tool for this project; no Maison Meta image or source code was copied. Original PNGs are retained under assets/images; WebP files are optimized delivery versions.

## Editorial

- Original: assets/images/editorial-source.png
- Web: assets/images/editorial.webp
- Prompt:

Use case: ads-marketing. Create one photorealistic luxury fashion editorial photograph for SOOROOH, a Korean experimental fashion creative studio website. Wide landscape 1536x1024 composition. Full body adult East Asian female fashion model on the RIGHT HALF of frame, dressed in sculptural flowing ivory silk cape dress and dark tailored trousers, standing in a pale warm gray monumental concrete courtyard, large draped cream fabric billows diagonally toward center in wind, natural editorial sunlight, directional shadows, subtle film grain, refined architectural minimalism, soft desaturated stone palette, realistic fabric texture, sophisticated high-end magazine art direction. Left half mostly clean textured gray wall and negative space for website headline overlay. Model looks away from camera, serene expression. Entire scene artful and realistic. No text, no letters, no logos, no watermarks. Not a website screenshot.

## Other assets

- geometric.svg, floral.svg, abstract.svg, texture.svg: original code-generated vector pattern studies, not AI-generated fabric photos.
- sketch.svg: original vector illustration of a draped silhouette; not an input used to generate the editorial image.
- quiet-form.mp4: silent, eight-second camera zoom of editorial.webp, rendered locally. Not AI-generated video. Rebuild with scripts/create-motion.mjs using a local Playwright install and the development server.
- All sample status labels must remain when these assets are shown as service concept examples.


## Brand font

SOOROOH wordmarks use the user-specified Paperozi CSS family (Paperlogy font files), weight 600. Weights 100–900 are bundled unchanged under assets/fonts from https://cdn.jsdelivr.net/gh/projectnoonnu/2408-3@1.0/. The accompanying SIL OFL license is included in assets/fonts/LICENSE.txt and the deployment export.
